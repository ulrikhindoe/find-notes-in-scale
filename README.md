# Find Notes in Scale

This application helps you train to find the notes in a scale based on the degree. It is a simple HTML page with JavaScript and CSS included.

## Features

- **Random Key Selection**: Automatically picks a random key (e.g., C minor) when the page loads or when the "Pick Random Key" button is clicked.
- **Natural Minor Scale**: The application uses the natural minor scale for all exercises.
- **Degree and Note Display**: Displays a degree (e.g., 1st, 2nd) and, after a delay, shows and plays the corresponding note.
- **Customizable Delay**: Allows you to set the delay (1-10 seconds) between showing the degree and playing the note.
- **Customizable Exercise Length**: Lets you specify the number of degrees (default is 20) before the exercise stops.
- **Stop Button**: Provides a button to stop the exercise at any time.
- **Sharp/Flat Note Display**: Ensures that notes match the sharp or flat nature of the selected key.
- **Modern Design**: Styled with CSS for a clean and user-friendly interface.

## How to Use

1. Open the `index.html` file in a browser.
2. Adjust the delay and number of degrees using the input fields.
3. Click "Pick Random Key" to select a key or use the automatically selected key.
4. Click "Start" to begin the exercise.
5. Follow the displayed degrees and listen to the corresponding notes.
6. Click "Stop" to end the exercise at any time.
